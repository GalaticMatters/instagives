# Instagives

Instagives is a public directory of free tools for [instafives.com](https://instafives.com). The home page groups every tool by category. Choosing a tool opens its own page in a new tab.

Calculators, converters, image helpers, and small utilities run in the browser. Files and clipboard notes stay on the device. A few names are short guides, because a safe in-browser version is not available yet. Health and money results are estimates, not advice.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:47291](http://localhost:47291).

The dev server listens on `0.0.0.0` port `47291`.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — production server on the same port
- `npm run lint` — lint
